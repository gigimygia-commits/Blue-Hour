# Blue Hour – Creative Coding Project

## About My Project

Blue Hour is an original R&B instrumental music project that I created using TunePad and Python.

Blue hour is the short period between daylight and darkness when the sky turns deep blue. I chose this name because I wanted my music to capture that calm, dreamy and slightly sad feeling.

My main idea was to explore how something logical, like coding, could be used to create something emotional, like music.

I used different sounds, including keys, bass and drums, to create a relaxing R&B composition.

## How I Used Python

I used Python to control the notes, rhythm, timing and different layers of my music.

Some important coding features I used include:

- **playNote()** – Plays musical notes and chords.
- **rest()** – Adds pauses between sounds.
- **for loops** – Repeats musical patterns without writing the same code many times.
- **Lists** – Stores groups of notes and chords.
- **Variables** – Stores values that I can use in my code.
- **beats** – Controls the duration and timing of notes.
- **velocity** – Changes how strong or soft the notes sound.

## Music Structure

I created my music using different layers:

- **Keys:** Create the chords and dreamy atmosphere.
- **Bass:** Adds a deeper sound and supports the rhythm.
- **Drums:** Create the beat using different drum patterns.
- **Additional keys:** Add more musical layers and variation.

I experimented with different note lengths, rhythms and velocity values to make the music sound smoother and less robotic.

Through this project, I learned how coding can be used creatively to make music.
